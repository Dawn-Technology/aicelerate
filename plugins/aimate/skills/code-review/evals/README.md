# Code review evals

Use these scenarios to check that a change to the code-review rules does what you meant, and nothing else. Run this when maintaining the skill, not during ordinary code reviews.

Compare the previous and proposed skill against [the fixed scenarios](scenarios.json) in separate contexts. Supply the same scenario inputs and shared context to both, and keep expected outcomes hidden until the reviews are complete. Compare missed problems, unsupported findings, remediation scope, and output-contract compliance, not finding counts alone. Record actual differences without claiming that a single comparison proves reliability.
